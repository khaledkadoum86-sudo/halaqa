# المدرسة القرءانية النموذجية

تطبيق لمتابعة حضور الطلبة وحفظهم. البيانات تُحفظ على جهاز المستخدم فقط، ولا يحتوي هذا المستودع على أي بيانات طلبة.

📘 **[دليل التطبيق للمعلّم وللمبرمج](دليل-المطور.md)**: كيف بُني التطبيق، وأين تُحفظ البيانات، وكيف تعمل المزامنة والحماية، وماذا تفعل عند أي مشكلة.

## خزانتي

في المجلد `khizana/` تطبيق شخصي مستقل للأستاذ: الكتب والأعمال والملفات وجهات الاتصال والمذكرات. يُفتح من `https://khaledkadoum86-sudo.github.io/halaqa/khizana/` ويتزامن بحساب Firebase نفسه في `users/<uid>/khizana` و`users/<uid>/khizana_blobs`. له Service Worker خاص به، وSW تطبيق المدرسة يتجاهل هذا المجلد.
